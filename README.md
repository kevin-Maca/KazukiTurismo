# KAZUKI TURISMO

Sistema web de turismo rural comunitario que permite a los visitantes consultar alojamientos, verificar disponibilidad, realizar reservas y registrar pagos por transferencia bancaria, promoviendo el turismo sostenible y el apoyo a las comunidades locales.

## Descripción del proyecto

Kazuki Turismo es una aplicación web desarrollada para facilitar la gestión de alojamientos rurales, fechas disponibles, cupos y reservas de visitantes.

El sistema cuenta con una interfaz para los visitantes y un módulo administrativo para la gestión de la disponibilidad de los alojamientos.

## Tecnologías utilizadas

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- TypeScript
- API REST

### Base de datos
- SQL Server

### Herramientas
- Git y GitHub
- Visual Studio Code

## Funcionalidades implementadas

- Registro e inicio de sesión.
- Consulta de alojamientos.
- Consulta y gestión de fechas disponibles.
- Gestión de cupos y capacidad.
- Registro de reservas.
- Registro de pagos por transferencia bancaria.
- Consulta de reservas del usuario.
- Actualización del perfil y cambio de contraseña.
- Panel administrativo.

## Estructura del proyecto

- `backend/`: lógica del servidor, API y servicios.
- `database/`: scripts y estructura de la base de datos.
- `kazukiTurismo/`: aplicación frontend.

## Ejecución del proyecto

El proyecto requiere Node.js, npm y SQL Server.

Los componentes frontend y backend deben ejecutarse por separado, utilizando sus respectivas configuraciones y dependencias.
